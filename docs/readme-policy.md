# README Policy

## Purpose

- 저장소 README를 설치/탐색 중심의 입구 문서로 유지합니다.
- 스펙 문서와 README의 역할을 분리해 변경 충돌을 줄입니다.

## Scope

- `README.md`
- `skills/README.md`

## Rules

1. `README.md`는 설치법, 스킬 목록, 문서 링크를 중심으로 유지합니다.
2. 실행 계약/검증 규칙/예외 정책은 `docs/*.md`에 기록합니다.
3. 하나의 주제는 하나의 SSOT 문서로 관리하고, README에는 링크만 둡니다.
4. README끼리 동일 본문 복붙을 금지합니다.
5. 문서 변경 PR에는 "README 중복 서술 없음" 확인 항목을 포함합니다.
