# Naming Conventions

## Repository

- `idencosmos-agent-skills`

## Skill folder and name

- Use lowercase kebab-case.
- Match folder name and frontmatter `name`.

## Skill package structure

- Keep each skill markdown-only: `SKILL.md` + optional `references/*.md`.
- Do not add `scripts/`, `assets/`, or extra top-level docs inside a skill folder.

## Script names

- Use kebab-case shell script names.
- Keep scripts idempotent where possible.
